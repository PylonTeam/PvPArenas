# Deprecated Jungle World Gen admin tool

This archive preserves the DEBUG ErkySSC Jungle World Gen admin panel, its recipe/settings/networking code, and local tests. It is excluded from compilation and mod packaging, including DEBUG builds.

`AdminTool/` contains the tool sources. `Integration/` contains snapshots of the active files before the tool hooks were removed; use these as restoration references, not replacements for newer active files. `Tests/` contains local test sources and is ignored by Git.

The normal mirrored vanilla underground Jungle generator remains active with its default pass recipe and random seeds. The admin panel, preview round phase, and its packet handlers are inactive.
